# Evergreen Division Tools

Free planning tools from the Evergreen Division (Cutco / Vector Marketing): https://evergreen-division.github.io

- Each tool in its own folder (`winter-break-launch-calendar/`, `campaign-planner/`, …) opens with sample data. Use **Load your own data** to see your team; your data stays in your browser.
- To make your own copy: click **Use this template** or **Fork**, or download the ZIP, then turn on GitHub Pages in your copy (Settings → Pages → main / root).
- `team/` holds password-protected versions with real data for the Evergreen team only.
